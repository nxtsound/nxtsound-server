# Community plugins

Plugins written and maintained by people outside the NxtSound project. They are **not reviewed or endorsed** by the project: a plugin runs with the rights of your server,
so read what it does and only install plugins you trust. Problems with a community plugin go to its own repository.

## Get your plugin listed

Open a pull request that adds a row to the table above. A plugin can be listed if:

- it is open source with a license that lets others use it, and has a README that explains installing and setting it up;
- it follows the [plugin protocol](../PLUGINS.md) and passes `plugincheck.py`;
- it does not collect data about users without saying so, and does not ask for more access than it needs;
- it does not help to get around technical protection measures, paywalls, or the terms of a service, and it does not offer content that is shared without the rights holder's permission;
- the author takes responsibility for it (contact, issues) and says which versions of NxtSound it works with.

We may decline or remove a listing, for example when a plugin becomes unmaintained, turns out to be unsafe, or draws legal complaints.
Not being listed does not stop anybody from publishing or using a plugin: the plugin system is open, the list is only what the project points to.
